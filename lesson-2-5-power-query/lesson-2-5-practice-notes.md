# The Applied Steps you built and what each one does

Source – Loads the original data into Power Query.
Changed Type – Sets each column to the appropriate data type.
Trimmed Text – Removes extra spaces from the Channel column.
Capitalized Each Word – Standardizes the text by capitalizing the first letter of each word of channel column.
Replaced Value – Replaces the hyphen (-) with a space to standardize the values of channel column.
Filtered Rows – Filters the data so that only records with Spend column greater than 0 remain.
